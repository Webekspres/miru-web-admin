## Aturan Keras

- **JANGAN** menulis kode sebelum membaca seluruh file di atas.
- **JANGAN** mengubah struktur yang sudah ada tanpa membaca konteks terlebih dahulu.
- Periksa `AGENTS.md` untuk panduan spesifik Next.js version — versi Next.js mungkin memiliki API yang berbeda dari yang Anda ketahui.
- Ikuti pola arsitektur yang sudah ditetapkan: folder-based routing, server components by default.
- Jaga konsistensi styling dengan Tailwind CSS (Tailwind v4, periksa `postcss.config.mjs`).
- Semua state management menggunakan React hooks (SWR/React Query untuk server state).
- JANGAN gunakan type `any` — Type safety dengan TypeScript strict mode.
- Untuk perubahan komponen yang diekspor, cari dan update SEMUA pengguna komponen tersebut.

## Referensi Cepat

- Framework: Next.js 16 (App Router)
- Bahasa: TypeScript (strict mode)
- Styling: Tailwind CSS v4
- UI Library: Headless UI (dari Tailwind ecosystem)
